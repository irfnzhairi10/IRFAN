# video-pertama — ujian HyperFrames

Video ujian 3 s, 540x960, teks "Ujian berjaya" dengan animasi 2D (reveal teks, transform shape, hold baca).

- `index.html` — komposisi root (540x960, 3 s)
- `compositions/ujian.html` — scene tunggal
- `assets/vendor/gsap.min.js` — GSAP 3.15.0 (lokal, tiada rangkaian semasa render)
- `snapshots/v1/` — gambar komposisi untuk approval frame (belum ada MP4)

Semak: `npx hyperframes check` · Snapshot: `npx hyperframes snapshot`
